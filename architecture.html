Принцип

Semantic Layer Agent оперирует понятиями вида EconomicCapital.value и операциями каталога (get_value, explain_change).

SQL Agent переводит Semantic Query в SQL, используя Mapping: economic_capital_fact.economic_capital — только на физическом уровне.

Semantic Layer Agent не генерирует SQL и не знает физические имена полей.
